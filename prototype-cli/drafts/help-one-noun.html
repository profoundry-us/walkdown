Usage: walkdown threads <verb> [arguments]
A thread is a note or a question on a rule or a screen.
list list the open threads
new --rule <id>|--screen <id> "<text>" start a note or a question
show <thread> print a thread and its replies
reply <thread> "<text>" add a reply, status unchanged
set <thread> --status <status> [--reply "<text>"]
change its status, with a reply if given
walkdown threads on its own runs list.
[exit 0]
