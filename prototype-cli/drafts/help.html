~/shop $ walkdown help
walkdown keeps a spec beside your project: rules, the threads about them, and the runs that check them.
Usage: walkdown <noun> [verb] [arguments]
A noun on its own lists them. walkdown <noun> help shows one noun's verbs.
Getting ready
init get walkdown ready on this machine
skills link walkdown's skills into Claude Code
where show where each blueprint and its records live
Blueprints
blueprints list this project's blueprints
blueprints new [<id>] start a blueprint for this project
blueprints import <path> register blueprints a repository declares
blueprints rename <id> <new> change a blueprint's id
blueprints commit none|spec|all
keep a blueprint in the repository, or out
blueprints forget <id> take a blueprint off this machine's list
pointer show which blueprint this project points at
Records
records move <kind> --to <path>
keep runs, threads, evidence or drafts elsewhere
Threads
threads list open threads
threads new|show|reply|set
start, read, answer or change a thread
Rules and verdicts
status [<rule>] what passes, and who each waiting item is for
lint check the blueprint for mistakes
run record the results of a test run
judge <rule> prepare a rule for an agent to judge
sweep --why <reason> mark every verdict so far as stale
hash print each rule's wording hash
rules move <rule> --to <id> move a rule to another blueprint, verdicts and all
The panel
serve open the panel in your browser
claims <url> which blueprint claims a page
[exit 0]
