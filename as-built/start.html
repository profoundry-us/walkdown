No blueprints open

A browser tab cannot read your filesystem, and walkdown both reads blueprints and writes threads and run records back to them. So it works through a small local server, which is the thing that actually holds the folder open.

In the directory holding your blueprints, run:

walkdown serve

Then every blueprint under that folder is listed here.
